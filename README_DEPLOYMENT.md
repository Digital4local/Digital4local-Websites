# Digital4Local — Deployment & HTDOCS Setup Guide

This package contains the complete, production-ready **Digital4Local AI Growth & Search Engineering Agency** website, Content Management System (CMS), CRM Leads Engine, and Authentication Portal.

---

## 📦 Package Contents:

1. **`C:\xampp\htdocs\digital4local\`** (Ready to run directly in local XAMPP)
2. **`digital4local_htdocs.zip`** (4.64 MB deployable archive for any cPanel / VPS / Shared Hosting)

---

## 🚀 How to Run Locally in XAMPP:

1. Open **XAMPP Control Panel** and start **Apache**.
2. Open your browser and navigate to:
   - **Main Website:** `http://localhost/digital4local/`
   - **Services:** `http://localhost/digital4local/services.php`
   - **Industry Blueprints:** `http://localhost/digital4local/industries/index.php`
   - **Blog & Playbooks:** `http://localhost/digital4local/blog.php`
   - **Admin Login:** `http://localhost/digital4local/admin-login.php`
   - **Page Manager Studio CMS:** `http://localhost/digital4local/admin-cms.php`
   - **CRM Command Center:** `http://localhost/digital4local/admin.php`
   - **XML Sitemap:** `http://localhost/digital4local/sitemap.php`

---

## 🌐 How to Deploy to Live Server (cPanel / Hostinger / GoDaddy / VPS):

1. Upload `digital4local_htdocs.zip` to your server's `public_html/` (or root web directory).
2. Extract the ZIP archive inside `public_html/`.
3. Ensure `.htaccess` is present in the root directory.
4. Set folder permissions for `config/` to `755` (read/write by PHP).
5. Open your domain in browser — website is 100% live with Zero MySQL setup required!
